Poprawki gry sieciowej do **KnightShift / Polanie II** (Steam 1.3).

**Instalacja:** pobierz `KSNetFix-2.6.3.zip`, rozpakuj, zamknij grę i uruchom `ZAINSTALUJ.bat` (albo skopiuj `dinput8.dll`, `steam_api.dll`, `ksnetfix.ini` obok `KnightShift.exe`). Szczegóły w `INSTRUKCJA.txt` w paczce.

### Poprawki
- **SteamNet, ranking:** gra zapisuje wynik meczu tylko w grach „rankingowych” starego EarthNet, więc po każdym meczu SteamNet wysyłała „bez wyniku”: rozłączenie znikało, a nikt nie dostawał wygranej ani porażki. KSNetFix odczytuje teraz wynik, który gra sama ustala (zwycięstwo, porażka, wyjście z menu), i liczy, kto opuścił mecz:
  - zwycięstwo +3 pkt, porażka 0,
  - wyjście z trwającego meczu (menu „Wyjdź”), gdy przeciwnicy grają dalej: rozłączenie (-1) zostaje,
  - kto zostanie w meczu sam, bo wszyscy przeciwnicy wyszli albo się rozłączyli, dostaje wygraną,
  - zamknięcie gry w trakcie meczu: rozłączenie zostaje (jak dotąd).
- **Gry RPG** nie liczą się do rankingu (w 2.6.2 na chwilę pokazywało się w nich rozłączenie).
- Log opisuje każdy wynik (`the game set match result …`, `match verdict …`), żeby łatwo sprawdzić, co zostało zapisane.

### Bez zmian
Reszta jak w 2.6.2. Wersje 2.1–2.6.3 grają ze sobą przez TCP/IP i Steam.

---
**English:** KSNetFix 2.6.3 makes SteamNet match results count. The game keeps a match result only for rated EarthNet games, so every SteamNet match ended "unrated". KSNetFix now hooks the game's result setter (victory, defeat, in-game menu quit) and counts who left the Steam session: victory +3, defeat 0, quitting a running match keeps the disconnect (-1), the last player left in a match wins, RPG games are not ranked.
