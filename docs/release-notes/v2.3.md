Poprawki gry sieciowej do **KnightShift / Polanie II** (Steam 1.3).

**Instalacja:** pobierz `KSNetFix-2.3.zip`, rozpakuj, zamknij grę i uruchom `ZAINSTALUJ.bat` (albo skopiuj `dinput8.dll`, `steam_api.dll`, `ksnetfix.ini` obok `KnightShift.exe`). Szczegóły w `INSTRUKCJA.txt` w paczce.

### Zmiany względem 2.2
- **Naprawione lobby po dołączeniu przez Steam:** host odsyłał dołączającemu graczowi listę graczy razem z nim samym, a ten nadpisywał swój lokalny wpis tą kopią. Gra traciła wtedy swój własny slot w lobby: „Gotowy” nic nie robił, a w slocie dołączonego gracza pojawiał się bohater innego gracza. Host 2.3 nie wysyła już dołączającego na liście, a klient 2.3 pomija samego siebie — naprawa działa, gdy **host albo dołączający** ma 2.3.
- Transport Steam: tryb anonimowego serwera gry (`[Steam] GameServer=1`) dla serwera dedykowanego — bez konta i bez zalogowanego klienta Steam. Zwykli gracze nie muszą nic zmieniać (domyślnie wyłączone).
- Paczka budowana automatycznie przez GitHub Actions (MSVC, ten sam `steam_api.dll` co w 2.0–2.2).

Wersje 2.1, 2.2 i 2.3 grają ze sobą (format protokołu bez zmian). Paczka 2.0 używała AppId 480 i nie widzi nowszych sesji.

### Stan testów
- Załadowanie DLL, przekazywanie `DirectInput8Create` do systemowego `dinput8.dll` i opóźnione ładowanie `steam_api.dll` (bez Steama powrót do DirectPlay) sprawdzone poza grą.
- **Jeszcze niesprawdzone w grze:** poprawka lobby i tryb serwera gry, pełna gra 2 graczy przez Internet/Steam oraz silnik `KnightShift.ex2`. Zgłaszaj wyniki i problemy w Issues z plikami `ksnetfix.log` od hosta i gracza.

Wymagania: Windows 10/11 z włączonym składnikiem DirectPlay, uruchomiony klient Steam, gra na koncie Steam każdego gracza.

---
**English:** KSNetFix 2.3 fixes the Steam lobby after joining: the host sent the joining player back to itself in the player list and the joiner replaced its local entry with that copy, so the game lost its own lobby slot ("Ready" did nothing, another player's hero showed up in the joiner's slot). It is fixed when either the host or the joiner runs 2.3. It also adds an anonymous Steam game-server mode (`[Steam] GameServer=1`, off by default) for the dedicated server. Compatible with 2.1 and 2.2. Not yet verified in a real game — please report results with `ksnetfix.log`.
