Poprawki gry sieciowej do **KnightShift / Polanie II** (Steam 1.3).

**Instalacja:** pobierz `KSNetFix-2.6.6.zip`, rozpakuj, zamknij grę i uruchom `ZAINSTALUJ.bat` (albo skopiuj `dinput8.dll`, `steam_api.dll`, `ksnetfix.ini` obok `KnightShift.exe`). Szczegóły w `INSTRUKCJA.txt` w paczce.

### Poprawki
- **Baner SteamNet w lobby:** w 2.6.5 zamiast logo był czerwony prostokąt. KSNetFix otwierał plik banera w trybie, który dla gry oznacza zapis, więc gra czyściła `SteamNet\Banner.tex` i nie miała czego wyświetlić. Teraz plik jest otwierany do odczytu, tak jak gra czyta swoje pliki z dysku. Uszkodzony plik z 2.6.5 zostanie sam nadpisany przy pierwszym wejściu do lobby.
- Logo jest wbudowane w `dinput8.dll`; w paczce nie ma osobnego pliku i nie trzeba nic dokopiowywać.

### Bez zmian
Reszta jak w 2.6.5. Wersje 2.1–2.6.6 grają ze sobą przez TCP/IP i Steam.

---
**English:** KSNetFix 2.6.6 fixes the SteamNet lobby banner showing as a red rectangle: 2.6.5 opened the file with flag 2, which the game's file layer treats as writing (CREATE_ALWAYS), so the banner file was truncated. The hook now opens it through the game's loose-file open (0x798E40 / ex2 0x79BB00) for reading and keeps the size like the game does. The banner is embedded in dinput8.dll.
