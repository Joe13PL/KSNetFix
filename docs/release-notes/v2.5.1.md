Poprawki gry sieciowej do **KnightShift / Polanie II** (Steam 1.3).

**Instalacja:** pobierz `KSNetFix-2.5.1.zip`, rozpakuj, zamknij grę i uruchom `ZAINSTALUJ.bat` (albo skopiuj `dinput8.dll`, `steam_api.dll`, `ksnetfix.ini` obok `KnightShift.exe`). Szczegóły w `INSTRUKCJA.txt` w paczce.

### Poprawka: SteamNet
- W 2.5 po wybraniu serwera „SteamNet — steam” gra pokazywała puste okna błędu i nie logowała. Przyczyna: pakiety logowania EarthNet są spakowane zlib, a serwer SteamNet wysyłał je bez kompresji. Teraz pakuje je tak jak dawny serwer EarthNet.
- Powitanie, odpowiedź na logowanie i wszystkie linie serwera (czat, szepty, kanały, gracze, gry) sprawdzone prawdziwym kodem gry uruchomionym w emulatorze procesora.

### Bez zmian względem 2.5
Reszta jak w 2.5 i 2.4. Wersje 2.1–2.5.1 grają ze sobą przez TCP/IP i Steam.

### Stan testów
- SteamNet nadal w trybie offline (logowanie, kanał z czatem, szepty, bohater RPG). Jeśli coś nie działa, ustaw `[SteamNet] Trace=1` i zgłoś problem w Issues z plikiem `ksnetfix.log`.

---
**English:** KSNetFix 2.5.1 fixes SteamNet from 2.5: the EarthNet login packets are zlib streams and the built-in server now sends them compressed, so logging in works instead of showing empty error boxes. Checked against the game's own client code run in a CPU emulator. Everything else is unchanged from 2.5.
